# Loja de Roupas e Joias

Projeto de loja virtual para apresentar roupas, joias e acessórios, acompanhado de uma área administrativa.

## Sobre o projeto

A página da loja apresenta a coleção. O painel administrativo permite gerenciar os produtos e as informações da loja.

## Recursos

- Página inicial e área de catálogo
- Painel administrativo com tela de acesso
- Cadastro, edição e remoção de produtos
- Categorias para roupas, joias e acessórios
- Campos para preço, descrição, imagem e estoque
- Controle de tamanhos e quantidades para produtos que usam grade
- Integração com Supabase para autenticação e armazenamento dos dados e imagens

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase

## Como visualizar

Abra `loja/index.html` para acessar a página da loja. Os arquivos do painel ficam na pasta `admin/`.

## Configuração

O painel depende de um projeto Supabase configurado para autenticação, banco de dados e armazenamento de imagens. Configure as credenciais públicas e os recursos necessários no Supabase antes de usar o painel.
